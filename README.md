Overview
This project was developed by me as part of the requirements for my Bachelor's degree in Computer Science. 
It is a fully functional electronic bookstore (called "Paradise Book Store") designed to serve both customers and store managers.

---

Documentation
The project includes the following documentation files to help the users and the developers to understand, set up, and operate the system:

  1. File "מסמך תכנון":
    - A detailed functional Description of what the system does.
    - The technologies used in the project.
    - Information about the system models, layers and architecture.
    - A database schema with an explanation of its structure and relationships.
    - A breakdown of all the pages, classes, methods and the components in the system, including their purpose and functionality.
    - A diagram illustrating the relationships between pages for each user mode (customer and manager).

  2. File "מסמך התקנה":
    Provides instructions for installing the system.

  3. File "מדריך למשתמש":
    This document serves as a guide for using the electronic bookstore system, including:
    - How to operate the system as a customer and as a manager.
    - Descriptions and screenshots of each page and its features.
    - Detailed instructions on how to interact with the system correctly and effectively.
